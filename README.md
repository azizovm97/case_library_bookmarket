## 📊 Описание данных
Используется набор данных о книгах, читателях, выдачах и отзывах библиотеки. Данные представлены в виде пяти таблиц:

- **books_list**: информация о книгах
- **readers**: информация о читателях библиотеки
- **book_issuance**: информация о выдаче и возврате книг
- **book_reviews**: отзывы и рейтинги книг читателями
- **genre**: список жанров книг

## 🛠 Используемые инструменты

- Python (DuckDB, Pandas, Plotly, Streamlit)
- SQL
- Jupyter Notebook для EDA-анализа
